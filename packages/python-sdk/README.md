# Generated Python SDKs (Phase 9)

Published ontology packages are emitted by `python -m ontology_platform.sdk --language python`
or the authorized SDK API. This directory is documentation, not a competing handwritten SDK.
The shared compiler is `services/api/src/ontology_platform/sdk/generator.py` and its public runtime
source template. Packages install independently and import no private backend modules.
See [SDK usage and contracts](../../docs/api/branching-sdk.md).
