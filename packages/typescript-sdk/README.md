# Generated TypeScript SDKs (Phase 9)

Published ontology packages are emitted by `python -m ontology_platform.sdk --language typescript`
or the authorized SDK API. Strict packages build independently using TypeScript 5.9.3 and Fetch;
no private Next.js imports are required. This is documentation for generated packages, not a second
schema or handwritten transport implementation. See [SDK usage](../../docs/api/branching-sdk.md).
