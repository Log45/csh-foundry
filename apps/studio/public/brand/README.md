# Foundry brand assets

Original supplied PNG artwork, preserved without modification:

- `foundry-magenta.png`: primary logo for light mode.
- `foundry-black.png`: primary logo for dark mode, on its original white background.
- `foundry-fiery-eye.png`: reserved alternate; not used by the interface or favicon.

The Studio brand component and browser-tab icons follow `prefers-color-scheme`.
The palette follows the same system preference; the default is dark when no light preference
is expressed. Logos are served directly without requiring a writable image-optimization cache.
